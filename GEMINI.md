# Repository Guidelines & Coding Rules

## 🚫 UI RULES: STRICTLY FORBIDDEN PULSE & DOT ICONS

1. **Dilarang keras memakai icon pulse baik yang kelap-kelip (`animate-pulse`) maupun tidak (statis).**
2. **Dilarang keras menggunakan dot/titik bulat indikator status** (`rounded-full` kecil berwarna hijau, putih, abu-abu, dll untuk indikator status).
3. Untuk status, selalu gunakan **teks tipografi bersih** (misal `AVAILABLE FOR WORK`, `STATUS: ONLINE`, `STATUS: ACTIVE`) atau badge teks biasa tanpa bulatan/dot.
